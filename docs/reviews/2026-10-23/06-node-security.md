# Node.js 보안 패치 확인

확인일: 2026-10-23 (Asia/Seoul). 이 문서는 수정 전 점검 기록입니다.

## 결론

패치가 필요합니다. 로컬 `node --version`은 **v26.5.0**이며, 저장소 `backend/Dockerfile:2`는 **node:20-alpine**입니다. 실제 운영 컨테이너 버전은 조회하지 않았습니다.

2026-10-21 공식 보안 릴리스는 **26.12.1 / 24.22.1 / 22.23.4**입니다. Brotli 디코더의 메모리 쓰기 오류(CVE-2026-111497), DNS·TLS 검증 관련 높은 위험도 수정 등을 포함합니다. 현재 26.5.0은 패치 이전 버전입니다. [공식 보안 공지](https://nodejs.org/en/blog/vulnerability/october-2026-security-releases)

Node 20은 지원 종료 상태이므로 Docker 태그를 그대로 갱신하는 것으로 이번 지원 버전의 패치를 얻을 수 없습니다. 운영용으로 패치된 LTS 계열을 선택해야 합니다. [Node.js 지원 현황](https://nodejs.org/en/about/previous-releases)

## 수정·검증 계획

- 저장소 Docker 기준을 **24.22.1 LTS**로 전환하고 개발 버전 파일·engines로 동일 기준을 명시합니다. [24.22.1 릴리스](https://nodejs.org/en/blog/release/v24.22.1)
- 프로젝트용 격리 런타임에서 의존성 설치·타입 검사·테스트·빌드를 검증합니다.
- 기존 전역 Node와 다른 프로젝트 환경은 변경하지 않습니다. 전역 26 계열을 계속 사용할 경우 26.12.1 이상으로 별도 갱신해야 합니다.
- 배포 시 새 이미지를 빌드하고 컨테이너를 재생성한 뒤 컨테이너 안에서 `node --version`을 확인해야 합니다. 저장소 수정만으로 실행 중인 프로세스가 갱신되지는 않습니다.

버전 기반 영향 여부를 확인했으며 취약점 악용 테스트나 운영 서버 검사는 하지 않았습니다. 애플리케이션의 모든 취약 경로가 외부에서 도달 가능한지 확정한 것은 아닙니다.
